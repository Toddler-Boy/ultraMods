Cheat Keys for Mass Effect (Legendary Edition)

What the mod does
Two key combinations in Mass Effect 1 run console commands the game already has:

- Shift+F11: 50,000 credits (AdjustCredits +50000)
- Shift+F10: 1,000 experience points (GiveXP 1000)

F10 and F11 on their own stay free and do nothing. Either Shift key counts.

Details
- Credits stop at the game's limit of 9,999,999. The usual credits notice shows the amount.
- Experience goes through the game's normal experience award: the squad levels up as usual, experience bonuses apply,
  and nothing is added at the maximum level.
- The keys work in normal play on foot, also with the squad command screen open. In the Mako only Shift+F10 works:
  the game's credits command does nothing while driving.
- They do nothing in menus, conversations, cutscenes and minigames.
- A controller can stay in use, the keyboard keys work beside it.
- Left Shift is also a game key: it opens the squad command screen or draws the weapon on foot and fires the boost
  in the Mako. Right Shift has no other function, so Right Shift+F10 and Right Shift+F11 do nothing else.

How it works
The mod adds its key bindings to the game's binding lists (BIOInput.ini inside Coalesced_INT.bin) as a config delta.
It does not replace the Coalesced file, so the settings of other mods stay as they are.

Install
Install it with ME3Tweaks Mod Manager (drag the zip onto it, then Apply).

Uninstall
Remove it in ME3Tweaks Mod Manager.
